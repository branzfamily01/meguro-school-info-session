# DECISIONS

更新: 2026-09-10 JST

## D-001 実装基準
ユーザー提示の `MASTER DESIGN SPEC v1.0` を今回の実装基準として使用する。設計上の重要原則は独断で変更しない。

## D-002 技術構成
静的HTML + CSS + 小さなVanilla JavaScript + Node.js事前生成を採用する。React / Three.js / GSAP / CMS / DB / PWAは初版へ追加しない。

## D-003 データ正本
日程・申込状態・URLをHTML/JSへ重複直書きせず、`data/events.json` を正本とする。原稿・写真・サイト情報も `data/` へ分離する。

## D-004 公開段階
学校確認前の訴求文・写真が残る間は `publishMode=preview` とし、検索エンジン向けに `noindex,nofollow` を付与する。公開用本番への切替は別途学校確認後。

## D-005 申込状態
`unknown / scheduled / open / full / closed / ended / postponed / cancelled` の8状態を使用する。受付開始は自動化せず、正式確認後のデータ更新と再ビルドで反映する。
